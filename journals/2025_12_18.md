- The directory structure of /sys/sdf is as follows:
- /sys/sdf            The base directory
  /sys/sdf/bin        User contributed programs
  /sys/sdf/lib        Associated libraries
  /sys/sdf/include    Header libraries
  /sys/sdf/share      Documentation and examples
  /sys/sdf/man        Manual page(s)
  /sys/sdf/info       Info page(s)
  /sys/sdf/etc        rc or configuration files
  /sys/sdf/src        Source code
- Accessing the Directory
  -----------------------

-

- To make use of the programs in /sys/sdf, set the following environment variables:
- PATH=${PATH}:/sys/sdf/bin
  MANPATH=${MANPATH}:/sys/sdf/man
